# meshioplusplus-occt

The OpenCASCADE add-on for [meshio++](https://github.com/loumalouomega/meshioplusplus). It registers a CAD kernel with the base wheel's shared core, which gives STEP and IGES reading and `fit_cad`'s OpenCASCADE backend.

```
pip install "meshioplusplus[occt]"
```

The add-on is pinned to the exact base version and is licensed `MIT AND (LGPL-2.1-only WITH OCCT-exception-1.0)`; the base wheel alone carries no copyleft code. See `doc/python_packages_plan.md` in the repository.
