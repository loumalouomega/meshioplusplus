# meshio++ logo

The current logo is built with **TikZ**: the **Stanford Bunny** mesh, read and rendered by meshio++ itself — `gen_logo_tikz.py` loads `example/Bunny.stl`, decimates it with PyVista, projects it through meshio++'s own 3D skin-rendering machinery (`meshioplusplus._projection`: orthographic isometric camera + painter's-algorithm depth sort, the same code that powers the SVG/TikZ writers for 3D meshes), and colours the triangles with the blue→teal gradient (a faux finite-element field), plus the `meshio++` wordmark.

**Attribution**: the bunny mesh is ["Stanford Bunny -- Digitized!"](https://www.thingiverse.com/thing:88208) by MakerBot, licensed under the [Creative Commons - Attribution](https://creativecommons.org/licenses/by/3.0/) license (committed as `example/Bunny.stl`).

## Regenerate

```sh
./build.sh          # needs pdflatex + dvisvgm (TeX Live) and the repo venv
                    # (meshioplusplus + numpy + pyvista + PyMuPDF + Pillow)
```

This runs `gen_logo_tikz.py` (generates the projected bunny mesh into `_mesh_icon.tex`), compiles `logo.tex`/`logo-icon.tex` with `pdflatex`, and converts to SVG with `dvisvgm`. PNGs are produced with PyMuPDF (or `pdftoppm`/`convert` if present), then `make_icon_assets.py` derives the square icon, `favicon.ico`, and the GitHub social-preview PNG (see below; skipped with a warning if PyMuPDF/Pillow aren't installed). After regenerating, sync the copies used by the docs site: `cp logo-with-text.svg ../public/logo.svg` and `cp logo-icon.svg logo-icon.png social-preview.png ../public/` — the last is the Open Graph / Twitter-card image `doc/.vitepress/config.mts` names, so the docs site's link previews follow the logo too (`favicon.ico` is written directly to `../public/` by `make_icon_assets.py`, no copy needed).

## Assets (committed)

| File | Use |
|------|-----|
| `logo-with-text.svg` | full banner (README, docs site) |
| `logo-icon.svg` | non-square icon (docs-site favicon/nav; content-cropped, not square) |
| `logo-icon-square.png` | icon padded into a square canvas (transparent), 512x512 — README badge, favicon source |
| `logo.png`, `logo-icon.png` | raster fallbacks of the two SVGs above |
| `logo.pdf`, `logo-icon.pdf` | print / vector source output |
| `social-preview.png` | 1280x640 banner-on-white, for GitHub's repo social-preview image |
| `../public/favicon.ico` | 16/32/48/64px multi-resolution favicon, derived from `logo-icon-square.png` |
| `repository-open-graph-template.png` | GitHub's own blank social-preview template (icon+wordmark / headline / subtext on a 1280x640 canvas with a red safe-area guide ~80px from each edge, "leave a 40pt border"); reference only, not consumed by any script — `make_icon_assets.py`'s `SOCIAL_PREVIEW_SAFE_MARGIN` was measured directly off its guide lines so `social-preview.png` fills that safe area instead of an arbitrary fraction of the canvas |

Sources: `logo.tex`, `logo-icon.tex`, `gen_logo_tikz.py`, `build.sh`, `make_icon_assets.py`. `_mesh_icon.tex` is generated (regenerated by `build.sh`).

### Uploading the GitHub social-preview image

GitHub has no config file or API for the repo's link/share thumbnail — it's a manual upload: **Settings → General → Social preview → Upload an image**, using `logo/social-preview.png`. Re-upload it whenever the logo changes.
