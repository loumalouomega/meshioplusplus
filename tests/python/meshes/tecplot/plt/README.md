# Tecplot binary fixtures

Each `<name>.plt` is a binary Tecplot file (`#!TDV112`) written by Tecplot's TecIO library (the classic `TECINI142`/`TECZNE142`/`TECDAT142`/`TECNOD142` API that `preplot` is built on, and `TECPOLYFACE142`/`TECPOLYBCONN142` for face-based zones), and `<name>.dat` is the ASCII file with the same content. Both are generated by `tools/gen_tecplot_plt_fixtures.py`, which describes each dataset once, writes the ASCII file itself and compiles a small TecIO driver for the binary one. The reader's acceptance test is that every `.plt` reads identically to its `.dat`.

TecIO was built from SU2's `externals/tecio/teciosrc` (Tecplot's royalty-free TecIO licence); no TecIO code is part of meshio++ or of these files beyond what TecIO writes.

| File | Content |
| --- | --- |
| `fe_mixed` | 3-D tetrahedron and brick zones, nodal `T`, cell-centred `P`, double precision; dataset, zone and variable auxiliary data, a text, a polyline geometry, custom labels and a user record in the header |
| `fe_2d` | single precision triangle, two quadrilateral and a line-segment zone: shared `X`/`Y`, a passive variable, shared connectivity, a user-defined face-neighbour connection; big-endian |
| `ordered` | I-, IJ- and IJK-ordered zones with a nodal and a cell-centred variable |
| `transient` | two strands at three solution times, sharing coordinates and connectivity |
| `poly_2d` | an `FEPOLYGON` zone (two quadrilaterals and a pentagon) with nodal `U` and cell-centred `Q`, and a second zone sharing its coordinates and face map |
| `poly_3d` | an `FEPOLYHEDRON` zone of two hexahedra sharing a face, a tetrahedron and a pentagonal prism (interleaved), and a second polyhedral zone whose face against the first is a boundary connection |
