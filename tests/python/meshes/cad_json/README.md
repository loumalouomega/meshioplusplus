# Kratos CAD JSON fixtures

Generated by `python tools/gen_cad_json_fixtures.py` from closed-form geometry and written with meshio++'s own writer, so every file is canonical: rewriting it gives the same bytes. None is copied from Kratos; the layout follows the schema Kratos's `CadJsonInput` reads (Teschemacher et al., *Realization of CAD-integrated shell simulation based on isogeometric B-Rep analysis*, AMSES 2018; `kratos/input_output/cad_json_input.h`) and the `Surfaces`/`Lines` dialect of its `ImportNurbsSbmModeler`.

| File | What it exercises |
| --- | --- |
| `plate_with_hole.cad.json` | A 4 × 4 plate of degree (2, 2) trimmed by a square outer loop and a circular inner loop of radius 1 (four rational quadratic arcs, exact circles); every trim is also a 3-D edge |
| `cylindrical_roof.cad.json` | The Scordelis-Lo roof: an untrimmed rational patch of degrees (2, 1), exactly an 80° arc of a cylinder of radius 25, knots in Kratos's reduced form |
| `two_patch_beam.cad.json` | Two trimmed patches joined by a coupling edge whose topology names both faces, a vertex, an embedded edge, a face named by `brep_name`, trims without control-point ids, and members meshio++ keeps verbatim |
| `import_square.json` | The import dialect: a bilinear surface with all-zero weights, four boundary lines and a rational quarter circle |
| `unit_cube.cad.json` | A closed solid for `mesh_cad_surface`: six bilinear faces trimmed by their parameter squares, twelve edges each naming its two faces |
| `capped_cylinder.cad.json` | A closed solid: a rational cylinder band (radius 1, height 2) closed through a seam edge used twice by the band, and two planar caps trimmed by exact circles that share the band's rims and start where they do |
| `sphere.cad.json` | A closed solid: two rational hemispheres (radius 1) sharing the equator, each closed through a seam and a degenerate pole edge with no 3-D curve |

`tests/python/test_cad_json.py` loads each file through Kratos's own `CadJsonInput` when `KratosMultiphysics` and `KratosIgaApplication` are installed.
