# meshio++ logo

The current logo is built with **TikZ**: the **Stanford Bunny** mesh, read
and rendered by meshio++ itself — `gen_logo_tikz.py` loads
`example/Bunny.stl`, decimates it with PyVista, projects it through
meshio++'s own 3D skin-rendering machinery (`meshioplusplus._projection`:
orthographic isometric camera + painter's-algorithm depth sort, the same
code that powers the SVG/TikZ writers for 3D meshes), and colours the
triangles with the blue→teal gradient (a faux finite-element field), plus
the `meshio++` wordmark.

**Attribution**: the bunny mesh is
["Stanford Bunny -- Digitized!"](https://www.thingiverse.com/thing:88208)
by MakerBot, licensed under the
[Creative Commons - Attribution](https://creativecommons.org/licenses/by/3.0/)
license (committed as `example/Bunny.stl`).

## Regenerate

```sh
./build.sh          # needs pdflatex + dvisvgm (TeX Live) and the repo venv
                    # (meshioplusplus + numpy + pyvista)
```

This runs `gen_logo_tikz.py` (generates the projected bunny mesh into
`_mesh_icon.tex`), compiles `logo.tex`/`logo-icon.tex` with `pdflatex`, and
converts to SVG with `dvisvgm`. PNGs are produced with PyMuPDF (or
`pdftoppm`/`convert` if present). After regenerating, sync the copies used
by the docs site: `cp logo-with-text.svg ../doc/public/logo.svg` and
`cp logo-icon.svg logo-icon.png ../doc/public/`.

## Assets (committed)

| File | Use |
|------|-----|
| `logo-with-text.svg` | full banner (README, docs site) |
| `logo-icon.svg` | square icon / favicon |
| `logo.png`, `logo-icon.png` | raster fallbacks |
| `logo.pdf`, `logo-icon.pdf` | print / vector source output |

Sources: `logo.tex`, `logo-icon.tex`, `gen_logo_tikz.py`, `build.sh`.
`_mesh_icon.tex` is generated (regenerated by `build.sh`).

## Old logos

The previous TikZ logo was a procedurally triangulated "FE surface blob"
(see the git history of `gen_logo_tikz.py`); before that, `logo.py` was a
pygmsh + optimesh generator (kept for reference — it needs
`pygmsh`/`optimesh`, which are not installed here).
